/ The ten questions

  1. Strategy scorecard — trades, win rate, net P&L, average R per strategy.
  2. Win rate by session — where does the edge actually live?
  3. Profit factor per bot — gross wins over gross losses.
  4. Running equity curve — cumulative P&L with a window function.
  5. Worst drawdown window — peak-to-trough per bot (CTE + window).
  6. Signal quality — do high-strength signals actually win more?
  7. Veto audit — what did the vetoes block, and why?
  8. ADX gate check — win rate above vs below the trend gate.
  9. Risk-rail audit — every halt and kill event, newest first.
  10. Daily P&L vs the 2% halt — did any day breach its rails?

/ A taste — Q5, worst drawdown

WITH curve AS (
    SELECT bot, closed_at,
           SUM(pnl) OVER (PARTITION BY bot ORDER BY closed_at) AS equity
    FROM trades
    WHERE closed_at IS NOT NULL AND is_manual = FALSE
),
peaks AS (
    SELECT bot, closed_at, equity,
           MAX(equity) OVER (PARTITION BY bot ORDER BY closed_at) AS running_peak
    FROM curve
)
SELECT bot, MIN(equity - running_peak) AS worst_drawdown_amount
FROM peaks
GROUP BY bot;
